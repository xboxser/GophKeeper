# Описание работы файлов

Файлы на сервер выгружаются без шифрования. Перед выгрузкой файла проверяется токен и "Мастер пароль". Мастер пароль задумывался как аналогичный функционал шифрования [Алгоритм шифрования данных](encryption.md), но не успел его реализовать.


Выгрузка файла происходит в отдельную tmp директорию. Перед началом выгрузки файла на сервер создается запись в БД со статусом `"add"`, если файл уже создан, то происходит его обновление и устанавливается статус `"upd."`.

Статусы файла:   
- `ok` файл выгружен и может быть доступен пользователю. 
- `add` выгрузка нового файла, файл не доступен для других действий
- `upd.` обновление файла, файл не доступен для других действий
- `down` скачивание файла, файл не доступен для других действий

У файла может быть только один статус, с одним файлом может работать только один клиент.

Если выгрузка прерывается, то данные из tmp директории удаляются. Запись в статусе `add` так же удаляется из БД, т.к. нет полностью скачанного файла. Запись в статусе `upd.` возвращается обратно в статус `ok`.

Так же предусмотрен функционал восстановления таблицы, при падение сервера. Во время его запуска срабатывает скрипт, восстанавливающий структуру таблицы с файлами по выше описанному алгоритму.

Если выгрузка успешно завершена, то файл из tmp перемещается в основное хранилище. При операции обновления данных, сначала удаляется файл из основного хранилища, а потом перемещается из tmp.


При скачивание файла, ему устанавливается признак `down` и убирается когда скачивание завершилось или прервалось.
